# CustomArithmeticToNASMCompiler_Public
This repository contains a compiler for a custom language that supports arithmetic operations over integers with literal constants and variables. The language also supports printing literals or variables to the console with the '<<' operator. The authoritative IR is minimal and consists of a symbol table and a collection of post order stacks for each valid line in the source file being compiled. The front end features a scanner generator that, if necessary, generates and serializes a single deterministic finite automata for a set of provided regular expressions via Thompson's construction and the subset construction. The resulting DFA allows the scanner to track typing information, and the generator only runs if DFA.txt does not exist. (Subset construction is O(2^n) so it's output is serialized and should only be deleted if the definition of the regular expressions or their associated types are changed.) The front-end also uses a custom table-driven parser for syntax validation, which is also generated dynamically from the grammar defined in `main()`, but I did not implement serialization for the constituent data structures due to time constraints and the relatively low real time costs of constructing them on every run. (all algorithms in the parser generator are P-time algorithms.) 
Currently, the compiler does not use any dynamic register allocation/spilling strategies because the scope of the project was restricted enough that the features were not necessary, but they are explicitly supported by the IR, the methods to manipulate those parts of the IR are just unimplemented.
The project is configured to target 32bit NASM, and none of the supported arithmetic operations handle overflow. There are a few files included that can be used to demonstrate certain features and provide examples of the language's syntax.
Outputs to a.asm, run with:  `nasm -felf64 a.asm -o a.o;  gcc -m64 -o a.x a.o -lc -no-pie; ./a.x`
